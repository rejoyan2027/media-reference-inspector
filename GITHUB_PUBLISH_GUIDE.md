# Media Reference Inspector v2.7.1 — GitHub to WordPress.org

1. Create a new GitHub repository called `media-reference-inspector`.
2. Extract this ZIP and add the CONTENTS of the extracted folder to the GitHub repository root (not the ZIP itself, and not within an extra enclosing folder).
3. Sign in to WordPress.org as the plugin committer (normally `codelith`). Create an SVN-specific password in https://profiles.wordpress.org/me/profile/edit/group/3/?screen=svn-password.
4. In your GitHub repository Settings > Secrets and variables > Actions > New repository secret, add:
   - `SVN_USERNAME`: `codelith` (only if that account has SVN commit permission)
   - `SVN_PASSWORD`: the SVN-specific password generated by WordPress.org.
5. Check `.github/workflows/deploy.yml` exists in the repository.
6. Go to GitHub Releases > Draft a new release; choose a NEW tag named exactly `2.7.1` on `main` (do not use `v2.7.1`), make it a normal release, then Publish release.
7. Go to GitHub Actions and verify the deployment job succeeds. If WordPress.org release confirmation is enabled, follow the confirmation email/dashboard.
8. Check https://wordpress.org/plugins/media-reference-inspector/ and test the update on a staging website.

Note: never commit the SVN password into source files. WordPress.org uses SVN for releases, not a direct GitHub ZIP upload. The deploy workflow runs only for published non-prerelease GitHub releases, not on every code change.
